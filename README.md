## 📌 Descripción del Proyecto

**Sistema de Préstamos SENA** es una solución tecnológica desarrollada para automatizar el registro, control y trazabilidad en la salida y devolución de herramientas, equipos tecnológicos y materiales de formación. Permite a cuentadantes e instructores llevar una auditoría en tiempo real sobre los elementos asignados a aprendices y ambientes de aprendizaje.

---

## 🚀 Módulos del Sistema

| Módulo | Características Principales |
| :--- | :--- |
| 👥 **Gestión de Usuarios** | Registro y control de Aprendices, Instructores, Cuentadantes y Administradores por documento de identidad. |
| 🏷️️ **Inventario de Elementos** | Registro de activos, placas SENA, números de serie, estado del equipo y ubicación en ambiente. |
| 📋 **Control de Préstamos** | Registro de solicitudes, entregas inmediatas, fechas límite de devolución y firmas de responsabilidad. |
| ⚠️ **Gestión de Sanciones** | Alertas por mora/retraso en devoluciones y bloqueo temporal para nuevos préstamos. |
| 📊 **Reportes y Auditoría** | Generación de paz y salvos, historial por aprendiz y reportes de estado de inventario. |

---

## 🛠️ Arquitectura Tecnológica

* **Backend:** Framework Laravel (PHP 8.2+)
* **Frontend:** Blade, Tailwind CSS / Bootstrap, JavaScript
* **Base de Datos:** MySQL / PostgreSQL / SQLite
* **Servidor Local:** Apache / Nginx (Laragon / XAMPP)

---

## ⚙️ Requisitos del Sistema

* PHP >= 8.2
* Composer >= 2.x
* Node.js >= 18.x & NPM
* Motor de base de datos relacional
